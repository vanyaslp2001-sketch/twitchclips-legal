# TwitchClips — сайт для GitHub Pages

## Что подготовлено

- `index.html` — полноценная главная страница с РАБОТАЮЩИМ локальным просмотром видео, редактором подписи, копированием и экспортом .txt.
- `features.html` — описание функций и процесса.
- `help.html` — FAQ, инструкции и поддержка.
- `privacy.html` и `terms.html` — новые, более детальные страницы политик.
- `style.css`, `app.js` — стили и JS редактора.
- `app-icon-1024.png` — загрузить в **TikTok Developer Portal → Basic information → App icon**.
- `favicon.png`, `favicon.ico` — ТО ЖЕ изображение, уменьшенное для вкладки браузера.

## Размещение

1. Откройте https://github.com/vanyaslp2001-sketch/twitchclips-legal
2. Code → Add file → Upload files. Распакуйте ZIP, загрузите файлы из этой папки непосредственно в корень репозитория (не саму папку!).
3. Согласитесь на замену index.html, terms.html и privacy.html, сделайте Commit changes.
4. НЕ УДАЛЯЙТЕ имеющиеся файлы `tiktok*.txt`: они используются для TikTok URL verification.
5. Дождитесь развертывания GitHub Pages и проверьте:
   https://vanyaslp2001-sketch.github.io/twitchclips-legal/
   https://vanyaslp2001-sketch.github.io/twitchclips-legal/privacy.html
   https://vanyaslp2001-sketch.github.io/twitchclips-legal/terms.html
   https://vanyaslp2001-sketch.github.io/twitchclips-legal/favicon.png
6. Поменяйте icon в TikTok Basic Info на `app-icon-1024.png` (НЕ favicon).
7. Пройдите все пункты правил и отправьте на Review заново.

## ВАЖНО: что этот набор НЕ делает

- Не реализует OAuth или публикацию в TikTok, не имеет серверной части.
- Не делает фальшивые кнопки «Войти через TikTok» или «Опубликовать».
- Не превращает существующую C# программу в доступную пользователям production-версию.
- Не гарантирует одобрение TikTok: TikTok требует готовый работающий продукт и видео реальной end-to-end интеграции.

Если основной продукт — C# WinForms Desktop:
- Выберите Desktop (а Web только при наличии реального веб-OAuth-потока).
- В Desktop Login Kit требуются redirect URI с `localhost`/`127.0.0.1`, портом и OAuth PKCE (см. https://developers.tiktok.com/docs/en/login-kit-desktop).
- Сначала реализуйте и протестируйте OAuth и соответствующую загрузку/публикацию, затем запишите ролик с реальным UI, согласием пользователя, scope и статусом операции.
- Сделайте доступной пользователям готовую сборку приложения и документацию; при необходимости добавьте ссылку на реальный релиз на сайт.
- Если используете настоящую backend-интеграцию, обновите Privacy Policy до фактической схемы сбора, хранения, удаления и передачи токенов.
- В описании Developer Portal указывайте только реально работающие функции, не делайте ложных обещаний.

## Проверка legal

Проверьте Terms/Privacy на соответствие реальной программе: они здесь описывают веб-редактор и условно — настольную интеграцию. Желательно добавить приватный контактный email и корректный адрес владельца/оператора данных до реального запуска; не вставляйте секреты и токены в публичный сайт.

## Примечание к модерации

Главная страница теперь включает реальный инструмент для обработки локального видео и метаданных, ссылки на документы доступны из навигации и подвала. Однако только изменение внешнего вида без полноценной работающей интеграции и корректного видео не достаточно для гарантированного одобрения.
