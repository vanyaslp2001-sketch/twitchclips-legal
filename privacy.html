Политика конфиденциальности

Редакция от 28 октября 2026 года.

1. Какие сведения обрабатываются на сайте

Веб-инструмент TwitchClips позволяет выбрать локальный видеофайл, ввести название, описание и ссылку на источник. Эти материалы обрабатываются скриптом в браузере и не загружаются на сервер TwitchClips. При закрытии страницы выбранный видеофайл и несохранённые данные редактора не сохраняются этим сайтом.

2. Браузерные функции

При использовании кнопки копирования текст передаётся в буфер обмена вашего устройства; при сохранении создаётся локальный текстовый файл. Сайт не использует собственные рекламные cookies и аналитические скрипты. Размещённый на GitHub Pages сайт может обрабатывать обычные технические запросы и журналы доступа в соответствии с политикой GitHub.

3. Настольное приложение и TikTok OAuth

Если пользователь отдельно устанавливает настольное приложение с интеграцией TikTok, приложение может запрашивать доступ к базовой информации профиля и разрешение на загрузку или публикацию видео исключительно после авторизации и согласия пользователя. Для работы интеграции могут использоваться OAuth-коды и токены, а сведения передаются TikTok по официальным API. Конкретный механизм хранения токенов и их удаления зависит от установленной версии настольного приложения и должен сообщаться в его интерфейсе или документации.

4. Цели и основания

Цель обработки — подготовить выбранные пользователем материалы и, при использовании отдельной авторизованной интеграции, выполнить запрошенные им операции. Действия, требующие разрешений TikTok, выполняются только после согласия пользователя на предоставление доступа.

5. Передача третьим лицам

Веб-редактор не передаёт локально выбранное видео TikTok, Twitch или владельцу сайта. При использовании отдельных интеграций данные могут передаваться соответствующим платформам для выполнения авторизованных действий согласно их собственным правилам.

6. Права пользователя

Пользователь может отказаться от выбора файла, закрыть страницу, удалить сохранённые файлы, а также отозвать разрешения для стороннего приложения в настройках соответствующего аккаунта. По вопросам обработки данных используйте контакт ниже.

7. Контакты

Связь по вопросам конфиденциальности — GitHub Issues проекта. Не публикуйте чувствительные сведения в публичных обращениях.
